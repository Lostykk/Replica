# Replica

Construí el shell inicial de Réplica: una app React 18 + TypeScript + Tailwind con tema oscuro profundo (#0B0D10 de fondo, #22E39B como color primario verde eléctrico, #8B7CFF violeta). 

Necesito solo la estructura base:

- Layout con sidebar colapsable en desktop y tab bar inferior en mobile

- 4 rutas vacías: Home, Llamadas, Ranking y Configuración

- El wordmark "réplica" en Sora 700 con la é en verde eléctrico como logo

- Un botón circular grande "Empezar llamada" en el centro del Home con pulso sutil

- Fondo con grano de ruido sutil (SVG noise al 3%)

Sin contenido real todavía, solo la estructura y el sistema visual base.
