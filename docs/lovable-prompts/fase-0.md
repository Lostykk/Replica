# LOVABLE PROMPT #0 — crear el frontend y su repositorio

Crear un proyecto llamado Réplica, simulador de entrenamiento de ventas para Latinoamérica. Idioma español rioplatense. Stack requerido: React 18, TypeScript estricto, Vite y Tailwind. No activar Lovable Cloud ni reemplazar Supabase, LiveKit o el worker Python externo.

En este paso inicializar solamente el proyecto; no fabricar pantallas con datos ficticios ni añadir claves de proveedores al frontend. La dirección de arte y la implementación de las diez pantallas se harán en la Fase 2 a partir de la especificación que enviaré.

Después, el owner debe conectar el proyecto desde Project settings → Git → GitHub y compartir la URL del repositorio generado. Mantener la aplicación en la raíz de ese repositorio. Se integrará a un monorepo existente como apps/web mediante submódulo, sin mover la raíz de Lovable.
