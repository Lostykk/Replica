# ADR-0003: fases y evidencia
La solicitud actual autoriza avanzar sin pausas de aprobación intermedias; los checkpoints del documento se registran con evidencia.
Las cuentas, la vinculación interactiva de Lovable y cualquier costo real pendiente se agrupan para el owner cuando bloqueen el siguiente paso.
Una fase con verificaciones pendientes no recibe un tag de fase completa. Las simulaciones locales no se presentan como pruebas de proveedores reales.
